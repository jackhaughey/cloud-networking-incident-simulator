# Troubleshooting Playbook

## General flow

1. **Detect**
   - Metrics, logs, customer reports.

2. **Triage**
   - Classify Severity (1/2).
   - Identify blast radius.

3. **Diagnose**
   - Network: BGP, routes, reachability.
   - System: CPU, memory, disk, processes.
   - Application: health, errors.

4. **Mitigate**
   - Roll back changes.
   - Apply targeted config fixes.
   - Use automation scripts where possible.

5. **Document**
   - Update incident record.
   - Capture RCA and follow-up actions.
